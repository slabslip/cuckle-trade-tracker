# Cooper's home — 3521 Prescott Ave

Knowledge pack for **Cooper's home agent**. Future agents should load this folder (and `.cursor/rules/coopers-home.mdc`) whenever the question is about the house, neighborhood, or city services.

| File | What it holds |
| --- | --- |
| `property.json` | Address, size, legal description, tax snapshot, sources |
| `HOUSEHOLD.md` | Day-to-day notes the family owns (rooms, vendors, quirks) |
| `city-services.md` | Dallas 311, water, power, gas, trash, emergency |
| `neighborhood.md` | Oak Lawn / 75219 context and nearby errands |
| `unknowns.md` | Open questions — fill these in as you live here |

**Privacy:** this repository also publishes a public football dashboard. Keep codes, logins, and account numbers **out of git**. Public-record facts (address, beds, tax roll) are already public; still do not copy this pack into `index.html`.
